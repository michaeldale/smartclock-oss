SmartClock-OSS 0.1.2 adds a password, an update check, night mode that follows the sun, and settings backup. It also frees 34 KB of flash for future features.

## ⚠ Upgrading from 0.1.1: the clock now has a password

After this update, the settings page and the **Smart Weather Clock** setup network both ask for the clock's password. The clock creates the password itself the first time it starts this version.

1. Install the update from the **Firmware update** card as usual.
2. Open the settings page and press **Show the password on the clock**. Read it off the clock and sign in. The clock hides it again as soon as you are signed in.
3. Optional: choose your own password under **System → Password**.

Anyone who can see the clock can show its password this way. Recovery mode (power on for under 10 s twice, then leave it on) is open and shows the password too, so you cannot lock yourself out.

## Download

**`SDPro_SmartClockOSS_v0.1.2.bin`**: one file for both the stock update page and our own. Keep the file name: the stock page only accepts names starting with `SDP`. It contains no WiFi details.

SHA-256: see `SHA256SUMS.txt` attached to the release.

## New

- **Password protection.** One password, generated on the clock, protects the settings page and the setup network (WPA2). Every change, including firmware uploads, needs you to be signed in. Five wrong attempts lock sign-in for a minute.
- **Update check.** The settings page tells you when a newer release is on GitHub. Your browser does the checking, so the clock needs no internet access for it.
- **Night mode from sunset to sunrise.** Dim the screen when it gets dark where you are, instead of at fixed hours.
- **Backup and restore** your settings as a file, plus **Forget WiFi** and **Reset all settings**. Backups contain no WiFi details or password.
- **Build ID** on the System card, so you can tell exactly which build is installed.

## Improved

- 34 KB of flash freed without removing anything. The image is now 92% of the update limit, down from 96%.
- Brightness changes respect night dimming straight away.
- Photo names with spaces display correctly.
- The first weather update after the clock connects to WiFi is more reliable.

## Install over the stock firmware

New to SmartClock-OSS? See the [README](https://github.com/michaeldale/smartclock-oss#install). The steps are unchanged, except that the setup network now uses the password shown on the clock's screen.
